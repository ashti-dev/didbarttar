## اجرا

فایل `index.html` را باز کنید، یا با Node.js پیش‌نمایش محلی را اجرا کنید:

```sh
node serve.mjs
```

آدرس پیش‌نمایش: `http://127.0.0.1:4173`.
سرور فقط به کامپیوتر محلی متصل می‌شود. برای ماندگاری قابل اتکای سبد بین صفحات، پیش‌نمایش HTTP توصیه می‌شود؛ رفتار localStorage در آدرس‌های file به مرورگر بستگی دارد.

## ساختار و ویرایش

- `build.mjs`: قالب مشترک هدر و فوتر، محتوای صفحات و تولید HTML.
- `shop-template.mjs`: الگوی مستقل فروشگاه و دسته‌بندی‌ها؛ کارت محصول و پنل فیلتر از داده مشترک ساخته می‌شوند.
- `product-template.mjs`: الگوی مستقل صفحه محصول و گالری بزرگ‌نمایی.
- `assets/js/catalog.js`: منبع مشترک اطلاعات محصولات و دسته‌ها.
- `assets/js/core.js`: منطق خالص جست‌وجو، فیلتر، پیشنهاد و اعتبارسنجی سبد.
- `assets/js/app.js`: منوی موبایل، فیلترها، مقایسه، کوئیز، سبد و فرم‌های محلی.
- `assets/css/theme.css`: طراحی مشترک صفحات و اندازه‌های موبایل، تبلت و دسکتاپ.
- `assets/css/shop.css` و `assets/css/product.css`: طراحی اختصاصی فروشگاه و محصول.
- `assets/images` و `assets/video`: تصاویر و ویدیوی موجود پروژه؛ ویدیوی نمایشی به‌عنوان خروجی مدل خاص معرفی نشده است.
- `.backups/original-template.zip`: نسخه اصلی HTML، CSS، JavaScript و README پیش از بازنویسی.

پس از تغییر قالب یا کاتالوگ، صفحات خروجی را دوباره تولید کنید:

```sh
node build.mjs
```

HTMLهای خروجی آماده میزبانی استاتیک هستند و در زمان اجرا نیاز به Node یا بسته ثالث ندارند. ویرایش مستقیم HTML با ساخت مجدد بازنویسی می‌شود.

## امکانات فعال

- جست‌وجوی نام و مشخصات با پشتیبانی از ارقام فارسی و نویسه‌های عربی.
- فیلتر کاربرد، طول کابل، ضبط تصویر و مرتب‌سازی؛ حفظ فیلترها در URL.
- دسته‌بندی سریع، برچسب قابل حذف برای هر فیلتر و پنل موبایل با مدیریت فوکوس، بستن با Escape و نمایش تعداد نتایج. تغییر فیلترها بلافاصله اعمال می‌شود؛ دکمه نمایش نتایج پنل را می‌بندد.
- مقایسه حداکثر سه محصول؛ مشخص کردن ردیف‌های متفاوت.
- صفحه مقایسه با انتخاب و حذف دستگاه در همان صفحه، حالت «فقط تفاوت‌ها»، سربرگ و ستون مشخصات ثابت هنگام پیمایش جدول، و توضیح جداگانه برای قطعات جانبی. با کمتر از دو محصول، حالت تفاوت‌ها غیرفعال است.
- راهنمای چهارمرحله‌ای با پیشنهاد وابسته به پاسخ‌ها و حالت بدون نتیجه.
- سبد محلی، تغییر تعداد، حذف، محاسبه جمع و دریافت خلاصه متنی انتخاب‌ها.
- ذخیره سبد و مقایسه در localStorage، همگام‌سازی میان تب‌ها و مدیریت داده خراب یا ذخیره‌سازی غیرفعال.
- فرم‌های آماده‌سازی متن درخواست، بدون ارسال اطلاعات؛ اعتبارسنجی شماره فارسی، انگلیسی و پیش‌شماره ایران.
- منوی موبایل، برچسب فیلدها، فوکوس صفحه‌کلید، لینک پرش و رعایت reduced motion.

## مرز نسخه نمایشی

قیمت، مشخصات و دسته‌بندی محصولات از داده‌های نمونه ساخته شده‌اند؛ نباید بدون تأیید مالک به‌عنوان اطلاعات فروش منتشر شوند. اتصال به پرداخت، موجودی، سفارش‌ها، ارسال فرم، شماره تماس تأییدشده، شرایط خدمات و دفترچه‌های واقعی هنوز وجود ندارد. فرم‌ها فقط متن را در همان صفحه آماده می‌کنند و اطلاعات شخصی را ذخیره یا ارسال نمی‌کنند. فونت از Google Fonts بارگذاری می‌شود و در صورت عدم دسترسی، فونت سیستم جایگزین است.

برای تبدیل به وردپرس، قالب مشترک را به اجزای پوسته منتقل کنید، داده محصولات و سبد را به WooCommerce متصل کنید و قیمت و موجودی را در سمت سرور اعتبارسنجی کنید. سبد محلی فعلی مرجع قابل اعتماد سفارش تجاری نیست.
