# LAYOUT CONTRACT

Define the geometry rules of the design.

## Container
- max width
- horizontal gutter
- nested container rules

## Grid
- columns
- gap
- alignment
- stacking

## Sections
- vertical rhythm
- section padding
- hero rules

## Responsive contract
For mobile/tablet/desktop/large desktop document:
- what stacks
- what wraps
- what hides
- what becomes scrollable
- what becomes sticky
- typography changes
- spacing changes

Do not derive a new layout system while coding if this contract already defines the behavior.
