# ADR — Architecture Decision Records

Use this file to record consequential decisions.

Each ADR should contain:

## ADR-XXX — Title
- Status: Proposed / Accepted / Superseded / Rejected
- Context:
- Decision:
- Alternatives:
- Consequences:
- Related specs:
- Date:

Do not use ADRs for trivial implementation details.

An architectural change should normally have an ADR before implementation.
