# ACCESSIBILITY

Target: WCAG 2.2 AA where practical.

Document:
- semantic HTML
- heading hierarchy
- landmarks
- keyboard navigation
- focus-visible
- focus management
- modal/drawer traps
- labels and descriptions
- error messaging
- color contrast
- reduced motion
- images/alt text
- ARIA only where native semantics are insufficient

Accessibility must be designed into components, not added as a final patch.
