# WOOCOMMERCE

Document the store contract.

Areas:
- shop/archive
- product card
- product single
- gallery
- price
- sale/stock
- variations
- add to cart
- cart
- checkout
- account
- related/upsell
- filters/sorting
- pagination
- breadcrumbs

For each area define:
- existing HTML reference
- required component
- WooCommerce data source
- states
- mobile behavior
- accessibility
- performance considerations

WooCommerce must be part of the architecture, not a late visual patch.
