# COMPONENTS

Inventory reusable UI components.

For each component document:
- purpose
- semantic structure
- variants
- states
- responsive behavior
- accessibility requirements
- dynamic data
- WordPress mapping
- WooCommerce mapping

Required state inventory where applicable:
Default, Hover, Focus, Active, Disabled, Loading, Error, Success, Empty, Selected, Expanded, Collapsed.

Do not create a component only because two pieces of markup look similar. Reuse must have a meaningful UI/behavior contract.
