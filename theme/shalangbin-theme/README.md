# قالب وردپرس شلنگ‌بین (ShalangBin)

قالب وردپرس فارسی و راست‌چین فروشگاهی بر پایه طراحی HTML شلنگ‌بین — برای فروش تجهیزات بازرسی تصویری (دوربین شلنگی/انداوسکوپ).

## نصب

1. پوشه `shalangbin-theme` را فشرده (zip) کنید.
2. در وردپرس: **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته** و فایل zip را آپلود کنید، سپس فعال کنید.
3. افزونه **WooCommerce** را نصب و فعال کنید و مراحل راه‌اندازی فروشگاه را کامل کنید.
4. در **تنظیمات ← خواندن** یک صفحه ثابت به‌عنوان «صفحه اصلی» انتخاب کنید تا قالب `front-page.php` نمایش داده شود.

## تنظیمات

- **نمایش ← سفارشی‌سازی**: متن نوار بالا، شماره تماس، شعار زیر لوگو، لوگوی سفارشی.
- **نمایش ← فهرست‌ها**: سه جایگاه منو (اصلی، نوار بالا، فوتر) در دسترس است.
- **ابزارک‌ها**: ستون کناری فروشگاه (فیلتر محصولات) و ستون کناری وبلاگ.

## ساختار فایل‌ها

```
shalangbin-theme/
├── style.css            # هدر قالب (متادیتا)
├── functions.php        # راه‌اندازی، اسکریپت‌ها، ووکامرس، کاستومایزر
├── header.php           # نوار بالا، هدر، جست‌وجو، سبد خرید، منو
├── footer.php           # فوتر و کپی‌رایت
├── front-page.php       # صفحه اصلی (هیرو، دسته‌ها، محصولات ویژه، وبلاگ)
├── index.php            # آرشیو وبلاگ
├── archive-product.php  # صفحه فروشگاه ووکامرس
├── single-product.php   # صفحه محصول
├── page.php, search.php, 404.php, sidebar.php, searchform.php
└── assets/
    ├── css/  (theme/shop/product/... + wp.css لایه یکپارچه‌سازی وردپرس)
    ├── js/   theme.js (منوی موبایل، هدر چسبان، سبد)
    └── images/
```

## نکات

- قیمت‌ها و موجودی از طریق WooCommerce مدیریت می‌شوند (سمت سرور و قابل اعتماد).
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ برای سرعت بیشتر می‌توانید آن را local کنید.
- برای درگاه پرداخت ایرانی (زرین‌پال و…) افزونه درگاه مناسب را جداگانه نصب کنید.
